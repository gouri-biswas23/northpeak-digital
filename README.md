# NorthPeak Digital

A premium, fully responsive one-page digital agency website built for the **Digital Heroes Web Development Internship Qualification Task**.

The project focuses on modern UI/UX, responsive design, accessibility, performance, semantic HTML, and clean frontend development using only Vanilla HTML, CSS, and JavaScript.

## 🎨 Design Decisions

The website follows a clean, premium design language inspired by modern agency websites.

Key design choices include:

- Deep Sea color palette
- Plus Jakarta Sans typography
- Large whitespace for readability
- Smooth micro-interactions
- Minimal, distraction-free layout
- Strong visual hierarchy
- Performance-first approach
